# Кавказский фронт

Браузерная многопользовательская стратегия о захвате провинций. Основа игры — карта `image.png` из корня
проекта: она выводится как есть, а поверх неё работает интерактивный слой провинций (SVG), построенный
по границам исходной карты.

## Быстрый старт

```bash
npm install
npm start          # http://localhost:3000
npm test           # юнит-тесты правил + сквозные тесты мультиплеера
```

Требуется Node.js ≥ 18.17. Чтобы проверить мультиплеер, откройте игру в двух окнах/браузерах (или с телефона
в той же сети по `http://<IP-компьютера>:3000`).

### Production-запуск

Отдельного шага сборки нет: фронтенд — нативные ES-модули без бандлера и без клиентских npm-зависимостей,
сервер отдаёт их со сжатием gzip и кэшем. Production-режим:

```bash
npm ci --omit=dev                 # только runtime-зависимости (express, compression, socket.io)
NODE_ENV=production npm start     # Windows cmd: set NODE_ENV=production&& npm start
```

При `NODE_ENV=production` статика (JS, CSS, карта) отдаётся с `Cache-Control: max-age=3600`.

### Переменные окружения

Все переменные необязательны. Секреты (логин/пароль TURN) задаются только в окружении (например, в
Render → Environment) и никогда не хранятся в репозитории.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт HTTP/WebSocket-сервера (Render задаёт сам) |
| `NODE_ENV` | — | `production` включает кэширование статики |
| `STUN_URLS` | STUN-серверы Google | список STUN через запятую для голосового чата |
| `TURN_URL` | — | TURN-сервер(ы) через запятую — нужен игрокам за строгим NAT / мобильным интернетом |
| `TURN_USERNAME` | — | логин TURN |
| `TURN_CREDENTIAL` | — | пароль TURN |

### Как подключить мультиплеер

Мультиплеер встроен в тот же сервер (Socket.IO поверх WebSocket, fallback на long-polling) — отдельный
бэкенд поднимать не нужно. Все игроки, открывшие один адрес сервера, попадают в общую комнату `global`;
для отдельной игры с друзьями введите одинаковый «Код комнаты» в меню.

## Как играть

1. **Играть** → экран выбора страны. Нажмите на страну на карте или в списке. Занятые страны помечены
   штриховкой и замком; при попытке выбора — «Эта страна уже занята».
2. **Объявить войну** → выберите соседнюю страну. На карте подсветятся только провинции противника,
   граничащие с вашей территорией.
3. Выберите провинцию. Шанс победы = `ваши войска / (ваши войска + войска противника) × 100%`
   (2000 против 10000 → 16.67%, 15000 против 10000 → 60%, 10000 против 10000 → 50%).
   Искусственного потолка нет, но пока у защитника есть войска, шанс меньше 100%.
4. Сражение идёт 10 секунд. Затем сервер бросает случайное число от 0 до 100: если оно ≤ шанса —
   побеждает атакующий, иначе защитник.
5. При победе провинция меняет владельца и у всех игроков заливается флагом победителя. Флаг страны —
   единая текстура, растянутая на всю её текущую территорию и обрезанная по форме провинций, поэтому
   захваченные земли выглядят продолжением флага. Границы провинций внутри страны — тонкий пунктир,
   границы между разными владельцами — заметнее.

Войска прирастают каждые 5 с (20 + 12 за каждую провинцию), после боя обе стороны несут потери.
Страна, потерявшая все провинции, уничтожается, а её игрок выбирает новую.

**Полный захват.** Когда у страны не осталось ни одной провинции, всем игрокам по центру экрана
показывается «АРМЕНИЯ ЗАХВАЧЕНА» (флаги обеих стран, звук, закрытие кнопкой или через 6 с). После
предпоследней провинции уведомления нет.

**Нагорный Карабах** разделён по внутренним линиям исходной карты на 6 самостоятельных провинций
`NK_01`…`NK_06` (свой контур, владелец, исходный владелец и соседи). Они захватываются по одной; атаковать
можно только провинцию, граничащую с вашей территорией.

### Телефоны и планшеты

- Карта масштабируется щипком двумя пальцами и перемещается одним; зум страницы браузера заблокирован.
- Кнопка **⛶ Полный экран** (на сенсорных устройствах) включает Fullscreen API и пытается повернуть
  экран горизонтально (`screen.orientation.lock('landscape')`). Если браузер это не поддерживает
  (например, iPhone Safari), игра остаётся рабочей и просит повернуть телефон вручную.
- Отдельный компактный HUD для портретной и горизонтальной ориентации: карта занимает весь экран,
  панели не выходят за его границы.

### Голосовой чат

Плавающая панель внизу справа. WebRTC (peer-to-peer, до 12 участников в комнате), сервер передаёт только
сигнальные сообщения. Две независимые кнопки: **🎙 Микрофон** (при выключении трек отсоединяется и
останавливается — звук не передаётся) и **🔇 Не слышать игроков** (глушит входящий звук, не трогая ваш
микрофон). Подсвечивается, кто говорит и у кого включён микрофон. Модуль WebRTC загружается только при
первом использовании чата. Микрофон в браузере работает только по HTTPS (на Render — автоматически) или
на `localhost`.

## Архитектура

```
image.png                  исходная карта (визуальная основа, не изменяется)
data/map.json              провинции: id, исходный владелец, соседи, контур, bbox, точка подписи
tools/build_map_data.py    генератор data/map.json из image.png (npm run build:map)
shared/                    общий код клиента и сервера: страны, флаги, правила и формула шанса
server/
  index.js                 Express (статика) + Socket.IO
  mapData.js               загрузка и проверка графа провинций
  game/GameRoom.js         вся игровая логика одной сессии (авторитетный сервер)
  game/RoomManager.js      комнаты / игровые сессии
  net/socketHandlers.js    события Socket.IO → действия комнаты, rate-limit
public/
  js/app.js                контроллер экранов и событий
  js/map/                  MapView (слой провинций поверх карты), PanZoom (мышь/тач/щипок)
  js/ui/                   меню выбора, HUD, окно войны, бой и результат, модалки, уведомления
test/                      node:test — правила, GameRoom, сквозной мультиплеер через socket.io-client
```

**Сервер — единственный источник истины.** Клиент отправляет только намерения
(`country:select`, `war:declare`, `battle:start`). Сервер проверяет всё сам: занята ли страна, есть ли
война, граничит ли провинция. Шанс и бросок (`crypto.randomInt`) считаются на сервере, поэтому подменить
результат с клиента нельзя. Одновременный выбор одной страны разрешается атомарно: Node.js обрабатывает
сообщения по одному, и побеждает первый запрос.

**Подключение и отключение.** Игрок получает `playerId` и секретный `token` (хранятся в `localStorage`).
После обрыва связи или перезагрузки страницы он возвращается к своей стране. Если игрок не вернулся
за 90 с, страна освобождается.

**Комнаты.** По умолчанию все играют в общей комнате `global`. В меню можно указать свой код комнаты,
чтобы играть с друзьями отдельно.

**Хранение состояния.** Игроки, их страны, владельцы провинций, войска, войны, последние сражения и
захваты хранятся в памяти сервера до его перезапуска (постоянная БД по заданию не требуется).

## Деплой на Render (бесплатный тариф)

1. Загрузите репозиторий на GitHub или GitLab.
2. Render → **New → Blueprint** → выберите репозиторий. Настройки подхватятся из `render.yaml`
   (web service, `plan: free`, `npm ci --omit=dev`, `npm start`, health check `/healthz`).
   Либо **New → Web Service**: Build `npm ci --omit=dev`, Start `npm start`.
3. Порт берётся из переменной `PORT`, которую задаёт Render. WebSocket на Render работает без настроек.
4. (Необязательно) для голосового чата у игроков за строгим NAT добавьте в Render → Environment
   `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` (см. таблицу переменных выше).

Ограничения бесплатного тарифа: сервис засыпает примерно после 15 минут без запросов, и первое
открытие после этого занимает около 30–60 с. При засыпании или передеплое состояние игры сбрасывается,
что соответствует требованию «хранить до перезапуска». Все игроки должны работать с одним инстансом:
состояние хранится в памяти, поэтому не включайте масштабирование на несколько инстансов.

## Перегенерация карты

Если вы замените `image.png`, выполните `npm run build:map` (нужны Python 3 и `pip install numpy pillow opencv-python`).
Скрипт выделит провинции по границам исходной карты, определит соседство и перезапишет `data/map.json`.
